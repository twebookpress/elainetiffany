# Elaine Tiffany Author Website

A static GitHub Pages-ready website for Elaine Tiffany.

## Upload to GitHub

1. Create a new GitHub repository (for example, `elainetiffany`).
2. Upload **the contents of this folder** to the root of the repository. `index.html` should be at the top level.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will display the public site URL after deployment.

## Files

- `index.html` — home page
- `books.html` — Black Cats and Magic series page
- `about.html` — author bio page
- `styles.css` — site styling
- `assets/images/` — author image and public book covers used on the site
- `assets/favicon.svg` — browser icon

Book Six's supplied cover is intentionally not included in the public site package because Books Six and Seven are being kept to title/mention-only teasers.
